# InstaCaption AI & PromptGenerate 🚀

> **AI-Powered Instagram Caption & Persona Prompt Generator**
> Craft viral Instagram captions, persona-tailored marketing prompts, call-to-actions, and targeted hashtags in seconds.

---

## ✨ Features

- **🎯 Persona & Audience Targeting**: Tailor prompts and captions specifically for entrepreneurs, creators, fitness enthusiasts, students, marketing professionals, and more.
- **📂 Diverse Categories**: Generate content across News, Productivity, Sales, Marketing, Social Media, Hiring, Business, Lifestyle, Tech, and more.
- **🎨 Multiple Tones & Writing Styles**:
  - Catchy & Viral 🔥
  - Professional & Clean 💼
  - Humorous & Relatable 😂
  - Minimalist & Aesthetic 🌿
  - Inspiring & Motivational 💡
  - Storytelling & Deep 📖
- **🌐 Multilingual Generation**: Support for English, Spanish, French, German, Hindi, Japanese, and more.
- **📏 Fine-Grained Controls**:
  - Configurable word count slider (30 – 300 words).
  - Format toggles (Captions, CTA buttons, Hashtags, Emojis, Clean plain text).
- **⚡ Instant Copy & Export**: One-click copy for complete captions, hashtags only, or raw prompts.
- **💎 Modern Glassmorphism UI**: Built with responsive layouts, smooth micro-animations, glowing gradient backdrops, and dark mode aesthetics.
- **📦 Self-Contained / Zero-Setup**: Runs directly in the browser with no build step required.

## 🚀 Getting Started

### 1. Direct Browser Preview
You can simply open `index.html` or `PromptGenerate.html` in any modern web browser:

- Open [index.html](file:///Users/nikhilbhanderi/Desktop/Persona-Promnt-Experiment/index.html) or [PromptGenerate.html](file:///Users/nikhilbhanderi/Desktop/Persona-Promnt-Experiment/PromptGenerate.html).

### 2. Local Live Server (Optional)
Run a lightweight HTTP server using Python or Node.js:

```bash
# Using Python 3
python3 -m http.server 8000

# Or using Node's npx
npx serve .
```

Then navigate to `http://localhost:8000` in your browser.

## 💡 How It Works

1. **Enter Topic & Audience**: Describe your post idea, product, or scenario.
2. **Select Parameters**: Choose your desired category, tone, language, and target word length.
3. **Customize Format**: Toggle hooks, hashtags, emojis, or call-to-actions.
4. **Generate & Copy**: Get instant, polished captions and persona prompts ready to post or feed into LLMs!
